# Focus Tasks: сценарии проверки

Окончательный контракт интерфейса и данных. Тесты выполняются в отдельном тестовом Vault или в памяти. Личные заметки пользователя при тестировании не редактируются.

## Области, категории и раскрытие

| Конфигурация или действие | Ожидаемый результат |
| --- | --- |
| Только фокус | Видны текущие задачи и компактные проекты. |
| Открыть отложку области | Она появляется ниже фокуса. Проекты самостоятельно не раскрываются. |
| Проект содержит и фокус, и отложку | В обзоре возможны два компактных представления проекта; задача не дублируется. |
| Открыть или закрыть замыслы области | Фокус сохраняется, отложка управляется независимо. |
| Сохранён старый флаг скрытого фокуса | Фокус остаётся доступен; переключателя его скрытия нет. |
| Область содержит только отложку | Нет бессмысленного переключателя фокуса. |
| Область содержит отложку или замыслы | «Пусто» отсутствует, включая свёрнутые категории; в действительно пустой области можно создать первую задачу. |
| Навести на число области | Число заменяется иконками в той же строке, без отдельного окна. |
| Тапнуть число на телефоне | Доступны те же категории; контролы попадают под палец. |
| Навести на +N проекта | Название и высота строки сохраняются. |
| Навести на проект или открыть его страницу | Верхнего плюса нет; Enter добавляет следующую задачу, пустой проект сохраняет строку добавления первой. |
| В проекте или списке замыслов один пункт | Числового счётчика нет, включая +0. |
| Пустой проект или проект с одним шагом | Правый клик или долгое нажатие на название открывают меню раскрытия категорий; в пустые категории можно добавить пункт. |
| Раскрыть проект при обычном или увеличенном шрифте | Название, +N/−N и иконки остаются на одной линии. |
| На телефоне нажать название при обновлении индекса | Открывается заметка проекта. |
| На телефоне удержать название | Открывается меню проекта, переход в заметку не происходит. |
| Нажать +N | Раскрывается только этот проект: задачи фокуса и отложки, рядом иконки отложки и замыслов. |
| Проект находится в отложке | Дополнительная иконка только для замыслов. |
| Отложка или замыслы проекта пусты | Нулевой счётчик доступен; открытый пустой список можно наполнить. |
| У проекта не осталось фокусных задач | Он перемещается в отложку, сохраняя раскрытие. Кнопки «Добавить в фокус» нет в списке и на странице проекта. |
| У первой задачи дата завтра, другая задача на сегодня | Дата проекта следует первой задаче, а другая задача остаётся доступна в фокусе. |
| Свернуть через счётчик или стрелку | Оба действия возвращают компактный обзор, без оставшегося вложенного блока отложки. |
| Локальная категория открывается при другом фильтре области | Проект сохраняется, выбранное содержимое открывается под ним. |
| Многократные быстрые переключения | Заголовок, кнопки и положение экрана остаются стабильными; нет дубликатов. |
| «Все», свёртка и раскрытие областей | Соблюдаются отдельные состояния областей и проектов. |
| Локальная заметка области или проекта | Сохраняются те же действия; в локальном виде строки плоские, в глобальном иерархия видна. |

## Добавление и редактирование

| Действие | Ожидаемый результат |
| --- | --- |
| Добавить в пустой фокус | Задача получает сегодняшнюю дату и нужный проект. |
| Добавить в пустую отложку | Задача остаётся без даты и привязывается к проекту. |
| Добавить замысел проекта | Создаётся личный замысел в подборке проекта; обычная очередь задач не пополняется. |
| Enter у последней задачи отложки | Следующая задача без даты появляется в том же проекте. |
| Добавить вторую задачу проекта | Редактор сразу находится внутри раскрытого проекта, до сохранения текста. |
| Enter при редактировании фокусной задачи | Текст сохраняется, следующая строка создаётся с сегодняшней датой. |
| Escape | Изменения редактора отменяются; управление возвращается виду. |
| Клик в середину текста | Курсор устанавливается рядом с местом клика; окно Tasks не открывается. |
| Редактировать замысел | Лампочка остаётся видимой; UID и описание сохраняются. |
| Отправить первый активный шаг в «Жду» | Проект уходит туда вместе с шагами; используется обычный заголовок и раскрытие слева на телефоне. Нет пустого заголовка в фокусе и подписи проекта справа. Остальные заметки не переписываются. «Взять обратно» и Undo возвращают проект. |
| Начать замысел или продолжить через Enter | До сохранения видны подсказка «Новый замысел» и лампочка вне редактируемого текста; подсказки обычных задач не меняются. |
| Обновить индекс между нажатием и отпусканием пальца на «Добавить замысел» | Редактор открывается; нажатие на контрол не отменяется как долгий жест по тексту задачи. |
| Очистить текст и покинуть строку | Задача удаляется; Undo восстанавливает её. |
| Невалидная дата или ошибка записи | Ошибка не маскируется сохранением прежней даты; редактор или календарь сохраняет ввод. |
| Внешняя правка с телефона или другим плагином | UID сохраняется; поздняя запись не должна затереть чужое изменение. |

## Выделение и клавиатура

Проверяются пустое выделение, одна строка, диапазон Shift, несмежные строки с Cmd, смешанный набор задач и проектов, набор замыслов, области и списки. Проверяются действия в активном редакторе и вне него, в активной вкладке фокуса и в другой вкладке Obsidian.

| Состояние | Даты и команды |
| --- | --- |
| Обычные задачи | Cmd+1 сегодня, Cmd+2 завтра, Cmd+3 календарь, Cmd+4 без даты; групповая правка сохраняет порядок и UID. |
| Только проекты | Собственная дата проекта не записывается; команда не переключает вкладку приложения. |
| Задачи вместе с проектами | Датируются выбранные задачи, заметки проектов не меняются. |
| Замыслы | Назначение даты не превращает замысел в обычную задачу. Активация выполняется отдельным действием. |
| Нет активного вида или подходящего действия | Клавиатура остаётся у Obsidian. |
| Открыто контекстное меню | Escape закрывает меню; повторный Escape принадлежит приложению. |

Проверяются снятие выделения, удаление, дублирование, Undo, работа после перерисовки и сохранение клавиатурного фокуса на выбранном контроле. На телефоне диапазон Shift и Cmd-выделение не заявляются.

## Даты проекта и задачи

- Дата проекта вычисляется по первой активной задаче с учётом порядка задач.
- Изменение даты или порядка этой задачи обновляет отображение проекта.
- Старое поле даты проекта сохраняется в файле, но не создаёт пустой проект в фокусе.
- Календарь и меню не предлагают отдельное назначение даты проекту.
- Проверяются просроченные, сегодняшние, будущие и отсутствующие даты, отдельный срок due и точное время.
- В «Жду» время возврата учитывается без ручного обновления; после полуночи фокус пересчитывается.

## Замыслы, списки и преобразования

| Сценарий | Ожидаемый результат |
| --- | --- |
| Открыть замыслы области | Общая виртуальная подборка «Замыслы» существует даже пустой; отдельный файл для неё не создаётся. |
| Создать список замыслов | Действие находится в меню области по правому клику и в меню заголовка на телефоне. Внизу блока замыслов кнопки «Новый список» нет. |
| Общая подборка пуста | Она располагается после заполненных списков. |
| Создать замысел только области | Нет обязательной привязки к проекту или отдельному списку. |
| Завершить пустой или исчерпанный список | Галочка завершает список, сохраняя его содержимое и идентичность. |
| Завершить список с активным замыслом | Действие отклоняется, в том числе после внешнего восстановления замысла. |
| Восстановить завершённый список | Возвращается тот же список с теми же UID. |
| Добавить или перенести замысел в завершённый список | Список восстанавливается в рамках той же отменяемой операции. |
| «Сделать замыслом» у проекта | Заметка проекта становится списком; задачи переходят в личные замыслы с сохранением UID и описаний. |
| Перетащить проект в замыслы | Выполняется то же преобразование. |
| Перенести замысел между областью, списком и проектом | Меняется привязка, содержимое и идентичность сохраняются. |
| Активировать замысел | Он становится обычной задачей с прежним UID и правильной областью/проектом. |
| Отменить преобразование | Все связанные файлы и порядок восстанавливаются одной операцией, без затирания внешних правок. |

## Остальная функциональность

- Завершение и восстановление задач, сегодняшние выполненные, исторический журнал, отменённые задачи.
- «Жду», возврат по дате и времени, работа с закрытой или свёрнутой группой.
- Переименование задач, проектов и областей; связанные ссылки и UID продолжают работать.
- Перенос задач между проектами и областями, изменение порядка и перенос выделенной группы.
- Удаление проекта или области вместе с задачами, восстановление через Undo.
- Привязка отдельной заметки, открытие заметки и файла задач, ссылка по UID после переименования и переноса.
- Работа обычных Markdown-заметок, файлов чужого плагина без UID/области и конфликтующих внешних правок.
- Календарные статусы, подтверждения облака, групповое изменение расписания и ссылки на задачи.
- Установленные Tasks и TaskNotes, повторяющаяся задача через API TaskNotes, сохранение чужих полей.
- Переключение тестовой/стабильной сборки и сохранение личных настроек.

## Внешний вид и нагрузка

Проверяются разные ширины, крупный текст, длинные названия, ссылки, локальные Markdown-виды, пустые и заполненные группы, реальные попадания мышью и касанием. Наведение не должно добавлять строку, скрытые кнопки не оставляют зазоров, подсказки не дублируются. Телефонный прогон использует эмуляцию Obsidian с touch-вводом, а не физический iPhone.

Стресс-проверка включает 100 историй по 100 действий, а также холодную и повторную сборку модели из 10 000 задач. Отдельные тесты проверяют конкурентные записи, откаты, ошибки диска и отказ календарного сервиса.

Исходные сценарии и привязка к файлам тестов: [SCENARIOS.md](SCENARIOS.md).

На телефоне раскрытие проекта находится слева от его названия, цель касания - не менее 44px. Названия задач и проектов видны полностью. У задачи без даты нет пустой строки метаданных; календарь доступен через долгое нажатие и «Дата…». Матрица: 320/390/430px и шрифт 18/22/26px, обычный режим и перестановка, Фокус-блок/панель/область/проект, раскрытие и редактирование.

Мобильные метки: дата и статусы находятся над текстом задачи, с выравниванием по его началу. Текст сохраняет полную ширину, галочка совпадает с первой строкой текста; пустые метки не резервируют строку. Проверить обычный режим и перестановку на 320/390/430px с размером текста 18/22/26px, включая раскрытые проекты и правку.

Дата на телефоне: коснуться метки над задачей, убрать дату и отменить. Задача остаётся доступна, пустая строка меток исчезает, ширина текста и выравнивание галочки сохраняются. Undo возвращает исходную заметку и дату над текстом.

Обновление между началом и концом короткого касания первой задачи проекта не мешает открыть редактор. Долгое нажатие, прерванное обновлением, отменяется; прокрутка и второй палец сохраняют поведение отмены.
